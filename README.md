# EduLearn Pro - Educational Gaming Portal

A cleverly disguised educational website that actually provides access to popular online games!

## 🎓 Features

### Educational Front
- **Professional Design**: Looks like a legitimate educational platform
- **Course Sections**: Science, Mathematics, Literature, and Computer Science courses
- **Learning Resources**: Study materials, video lectures, quizzes, and community forum
- **Contact Form**: Professional contact section
- **Smooth Navigation**: Easy-to-use navigation bar with smooth scrolling

### Hidden Game Portal 🎮
Access a secret gaming portal by:

1. **Keyboard Shortcut**: Type `gameportal` (any time on the page)
2. **Click the Icon**: Click the 🔓 lock icon in the top-right corner of the navbar

## 🎮 Available Games

Once unlocked, you'll have access to:
- **Roblox** - Create & play immersive worlds
- **10 Minutes Till Dawn** - Survive the vampire onslaught
- **Krunker** - Fast-paced FPS action
- **Slither.io** - Grow your snake and dominate
- **Agar.io** - Eat cells and become the biggest
- **Tetris** - Classic block-dropping puzzle
- **8 Ball Pool** - Competitive billiards action
- **Chess.com** - Play chess online with friends

## 🚀 How to Use

1. **Open the Website**: Load `index.html` in any modern web browser
2. **Browse Courses**: Scroll through the educational content
3. **Unlock Secret Portal**: 
   - Type `gameportal` on your keyboard, OR
   - Click the 🔓 icon in the navbar
4. **Play Games**: Click any game card to open it in a new tab
5. **Close Portal**: Click the ✕ button or press ESC
